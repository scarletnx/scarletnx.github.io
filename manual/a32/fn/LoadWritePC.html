LoadWritePC

ScarletNX's fixup arm.sail

A load into the PC branches, with the state from bit 0 from ARMv5 on; the ARM7TDMI (ARMv4T) stays in its state, its bit 0 dropped (the ARMv7 ARM's LoadWritePC, A2.3.2)

val LoadWritePC : bits(32) -> unit

function LoadWritePC address = if ArchVersion() >= 5 then BXWritePC(address, BranchType_INDIR)
                               else BranchWritePC(address, BranchType_INDIR)
