CurrentInstrSet

ScarletNX's fixup arm.sail

The instruction set a block runs in is the block's (the dispatcher picks an A32 or a Thumb block by CPSR.T): the back end answers it when it recompiles, and an instruction that selects the other one (BLX) has it from then on, so its branch aligns its target as the new set does (SetInstrSet, the back end's; PSTATE.T as sail-arm's SelectInstrSet)
