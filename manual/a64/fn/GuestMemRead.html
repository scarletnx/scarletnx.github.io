GuestMemRead

ScarletNX's fixup nx.sail

Guest memory is ScarletNX's own: the host's bytes at CPU.mem plus the address, read and written as the host does (llvm.h). An acquire load and a release store are sequentially consistent host atomics, which order both ways, so RCpc's acquire is the stronger one and LOR's limited ordering the full one (cpu.h)

val GuestMemRead : forall 'size. (bits(64), int('size), bool) -> bits('size * 8)
