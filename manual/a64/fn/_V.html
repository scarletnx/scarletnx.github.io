ScarletNX / ARM ISA

_V

ScarletNX's fixup nx.sail

ScarletNX's CPU keeps the 32 SIMD&FP registers as 128 bits each (cpu.h's CPU.v), and the NX has no SVE: sail-arm keeps them in _Z, SVE's registers of up to 2048 bits, which a write zeroes above the vector length. Here they are _V's elements, which the back end loads only as far as an instruction reads (sg__V_read_bits: a scalar's low lane)

register _V : vector(32, bits(128))

Used by

  • V_set
