GuestLoadExclusive

ScarletNX's fixup nx.sail

The exclusive monitor is cpu.h's, value based: the load-exclusive arms it with the value it reads, and a store-exclusive is a compare-and-swap from that value, which clears it. So the monitor is set by the load itself (GuestLoadExclusive, a pair's too: one access of all its bytes), the exclusive reads that follow take what it read (GuestExclusiveValue), whether the monitor passes is the compare-and-swap's answer, and the status is that store's

val GuestLoadExclusive : forall 'size. (bits(64), int('size)) -> unit
