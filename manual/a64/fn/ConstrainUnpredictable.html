ConstrainUnpredictable

ScarletNX's fixup nx.sail

A CONSTRAINED UNPREDICTABLE encoding (a load's write-back register or a pair's two registers the same, a store-exclusive's status register one it reads) runs as it is written: its registers are written in the order its Sail writes them, so a load's write-back comes after its loads and a store's data is read before its write-back, which is one of the UNKNOWN values Arm allows and what ScarletNX's emitters always did

val ConstrainUnpredictable : Unpredictable -> Constraint

function ConstrainUnpredictable which = Constraint_NONE
