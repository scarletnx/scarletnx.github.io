Logic

sm53_int.sail

the logic operation of two values: 0 and, 1 or, 2 xor, 3 the second

function Logic(op : int, left : bits(32), right : bits(32)) -> bits(32) =
    match op { 0 => left & right, 1 => left | right, 2 => EOR(left, right), _ => right }
