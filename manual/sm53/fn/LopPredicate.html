LopPredicate

sm53_int.sail

LOP: a's and b's operation (41-42), each inverted with 39 and 40; .CC (47) with .X (43); the predicate at 48 by the mode at 44-45: false, true, the result zero, not zero

function LopPredicate(value : bits(32), mode : int) -> bool =
    match mode { 0 => false, 1 => true, 2 => value == 0x00000000, _ => value != 0x00000000 }
