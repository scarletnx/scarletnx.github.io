ScarletNX / Maxwell ISA

Maxwell ISA: SM53

The instructions of the Switch's GPU (the Tegra X1's Maxwell, SM53) that ScarletNX's shader translator takes, laid out as Arm's reference lays an instruction out: each encoding's diagram (its opcode from sm53.decode, the fields the decoder and the Sail read) and the operation in ScarletNX's Sail. 154 instructions, 266 encodings; 140 with Sail.

The search takes a name (the nearest when none is the same) or a 64-bit instruction word in hex (0x5c58000000270004): its opcode is bits 63:48.

Instructions

  • Floating point instructions (31)
  • Integer, logic, video and predicate instructions (44)
  • System registers, votes, shuffles and barriers (6)
  • Attributes and varyings (7)
  • Constant buffer, local, shared and global memory instructions (12)
  • Branches, calls, returns, the control stack's pushes and pops, KIL and EXIT (21)
  • Texture and surface instructions (19)
  • Without Sail (14)
