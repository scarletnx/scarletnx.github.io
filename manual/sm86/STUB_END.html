LEPC (0x34e): the address of its own instruction into a register pair (CuAssembler's sm_86 record "LEPC R128"). A geometry program that ends through an exit stub adds the stub's offset to it and hands the sum to 0x357, which sets where EXIT goes on; the stub runs OUT and 0x957 before its own EXIT (nxnative's notes on one game's geometry program, MIT). No public table names 0x357 or 0x957

Runs execute_STUB.

STUB_SET and STUB_END: a geometry program's exit stub: STUB_SET sets where EXIT goes on, and the stub's OUT finishes the output. An invocation here has nothing left to finish when it ends (SPIR-V ends each primitive at the invocation's end), so EXIT ends it and the stub does not run
