Operation Sail

IMAD.WIDE and UIMAD.WIDE: NAK's OpIMad64, a * b (bit 73 signed) + the pair at c, into the pair at the destination. The carry out of the 64-bit sum goes to the predicate at 81-83 as IADD3's first (nvdisasm: IMAD.WIDE.U32 R14, P0, R10, R19, R14): one game's 64-bit division chains IMAD.WIDE ..., P0 into IMAD.X. With .X (bit 74; nvdisasm: IMAD.WIDE.U32.X R6, RZ, R5, R6, P1) the carry predicate at 87-90 joins the sum

let is_signed = Field(73, 1) == 0b1;
Int64();
let a32 = SrcInt(A);
let b32 = SrcInt(B);
let a64 = if is_signed then SignExtend(a32, 64) else ZeroExtend(a32, 64);
let b64 = if is_signed then SignExtend(b32, 64) else ZeroExtend(b32, 64);
if SrcIsImm(C) | SrcIsCbuf(C) then throw(Unsupported("%s with c an immediate or a constant", OpName()));
let chi = SrcNext(C);
let product = a64 * b64;
let clo = SrcBits(C);
var sum : bits(64) = product + (chi @ clo);
var carry : bool = UInt(sum) < UInt(product);
if Field(74, 1) == 0b1 then {
    let more = sum + CarryIn(87);
    carry = (if carry then true else UInt(more) < UInt(sum));
    sum = more
};
PredWrite(UInt(Field(81, 3)), carry, Uniform());
D_write(sum[31 .. 0]);
if DstHasNext() then D_writeNext(sum[63 .. 32])
