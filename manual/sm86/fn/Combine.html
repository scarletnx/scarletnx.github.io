Combine

sm86.sail

the predicates' combination at 74-75 (FSETP's, ISETP's): and, or, xor

function Combine(set_op : bits(2), x : bool, acc : bool) -> bool =
    match set_op {
        0b00 => x & acc,
        0b01 => x | acc,
        _ => x != acc
    }
