Bmov

sm86.sail

A write of a convergence barrier, whose value the structured translation does not keep (BSSY's writes neither), and which no translated instruction reads. The debug variants of the driver's programs start with BMOV.32 B0, 0xffffffff, BMOV.32 B1, B0 to BMOV.32 B15, B14 and BMOV.32 B15, 0x0. A state register (28-29 set, for BMOV.32 B, B at 16-23) is refused

function Bmov(at : int) -> unit = {
    let to = UInt(Field(at, 8));
    if to >= 16 then throw(Unsupported("%s into state register %u", OpName(), to))
}
