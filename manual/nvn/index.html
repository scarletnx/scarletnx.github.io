ScarletNX / NVN API

NVN API

NVN, the graphics API of the Switch and, as NVN2, of the Switch 2, as ScarletNX implements it on Vulkan: every function a game resolves (nvn.hook), with its signature and the handler that runs it, and the types and enums of nvn.h. NVN2 keeps the Switch's API and adds to it: what only Switch 2's drivers have is marked.

Switch 2 only in Switch 2's NVN (NVN2) Switch 1 only in the Switch's, which NVN2 dropped; no mark: both
