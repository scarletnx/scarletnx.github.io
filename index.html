If a Switch is an ARM64-verse.
Then ScarletNX is FEX but in reverse.

ScarletNX is a static recompiler for Switch and Linux ARM programs.
Runs on FreeBSD, Android, Windows, Linux, Solaris, NetBSD, OpenBSD, DragonFlyBSD, and AIX!
Runs on x86_64, aarch64, powerpc64le, riscv64, mips64, loongarch64, sparc64, and DEC Alpha!
Stay tuned on our Discord for updates.

We offer the following CI images:
Windows x86_64
Linux x86_64
Linux aarch64
Android
